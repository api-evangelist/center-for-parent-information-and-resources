## What is machine-readable here

CPIR runs no developer program and publishes no API documentation. It does, however, serve a real,
anonymous, read-only JSON API from its own host — the WordPress REST API behind parentcenterhub.org,
with the Connections Business Directory namespace `cn-api/v1` carrying the national Parent Center
directory. The API index at https://www.parentcenterhub.org/wp-json/ registered 34 namespaces and
717 routes on 2026-09-05.

The most useful thing here for an agent is the directory: 784+ Parent Center records, each with an
organization name, a work address, a geocoded latitude and longitude, telephone numbers, email
addresses and a public link, organised across 55 state and territory terms. That is the machine
answer to "which Parent Center serves this family?".

IMPORTANT — what is NOT readable: the WordPress content collections on this host are closed to
anonymous callers. /wp-json/wp/v2/posts, /pages, /media, /categories, /tags, /users and /search all
return `401 rest_forbidden`. CPIR's article content is available anonymously only through its RSS
feed. Do not plan an integration around the wp/v2 content routes.

## How to call it well

- Pagination is `page` and `per_page`. The host advertises X-WP-Total and X-WP-TotalPages in
  Access-Control-Expose-Headers but does NOT actually emit them on the directory collection, so page
  until you get an empty array rather than reading a total.
- Text fields come back wrapped as {"rendered": "..."} and HTML-entity encoded. Unescape before use.
- Errors are the WordPress envelope {"code","message","data":{"status"}} served as application/json.
  They are not RFC 9457 problem details.
- Respect `Crawl-delay: 600` from https://www.parentcenterhub.org/robots.txt. It is the only request
  rate CPIR states anywhere. No rate-limit headers are returned and no limit is documented.
- The directory `region` field is a two-letter subdivision code that matches the keys from
  /cn-api/v1/countries/us/regions. Joining the directory to a map is a join by value; there is no
  foreign key.
